## Setup
1. Clone the Repository
   ```bash
   git clone git@github.com:Schulze18/felan.git
   ```

2. Set Up Conda Environment
   ```bash
   conda env create -f felan_env.yml
   conda activate felan
   ```

3. Install FeLaN as a Python pkg
   ```bash
   pip install -e .
   ```
